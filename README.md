# ⚽ Sports Analytics Dashboard

An interactive web application designed to track and analyze personal football performance through data visualization, KPIs, and historical statistics.

🔗 Live demo: https://meuplacar.lovable.app/

---

## Overview

This project was created to solve a personal problem: keeping track of goals, assists, matches, and performance trends throughout the football season.

Since I could never remember my statistics accurately and couldn't find an app that matched my needs, I developed my own solution.

The application allows users to register matches, goals, assists, game results, and highlight videos, transforming raw data into actionable insights through interactive dashboards.

---

## Key Features

- Match registration
- Goal and assist tracking
- Win/loss analysis
- Historical records
- Performance trends over time
- Streak analysis
- Monthly comparisons
- CSV export
- Highlight video storage
- Mobile-friendly interface
- Progressive Web App (PWA)

---

## Key Metrics

- Goals per match
- Assists per match
- Goal contributions per match
- Win rate
- Points earned
- Personal records
- Current and historical streaks
- Monthly performance trends
